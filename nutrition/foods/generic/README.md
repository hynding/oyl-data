# nutrition/foods/generic

Unbranded foods from USDA FoodData Central, generated by
`pnpm fetch:usda && pnpm extract:usda && pnpm shard:usda`. Do not hand-edit — fix the
mapping in `scripts/nutrition/shard-generic.ts` or the reference tables and regenerate.

Layout: `<dataset>/<source-category>.yaml`, one reviewable YAML list per FDC food group
(SR Legacy, Foundation) or WWEIA category (FNDDS survey foods), sorted by name.

- `foundation/` — USDA's current lab-analyzed foods (few hundred, best data)
- `sr_legacy/`  — Standard Reference, frozen in 2018 (~7.8k foods; includes dated chain
  restaurant items such as "McDONALD'S, Big Mac", which get `brand` peeled off)
- `survey/`     — FNDDS, the dietary-survey database (~5k foods, "as eaten" composites like
  "Cheeseburger, from fast food", with household portions)

The same food often appears in more than one dataset; `shard-generic.ts` keeps one per
normalized name, preferring foundation > sr_legacy > survey.

Data: U.S. Department of Agriculture, Agricultural Research Service. FoodData Central.
Public domain (CC0) — see `../../../LICENSE-DATA.md`.
